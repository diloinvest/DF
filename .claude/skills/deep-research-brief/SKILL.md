# Deep Research Brief

The user wants a real research pass, not a summary of the first result.

## Method

1. **Gather 5+ sources minimum.** Prioritize primary sources (original
   studies, filings, documentation, first-party data) over secondary
   (articles about them). Mark each source as primary or secondary.
2. **Seek the opposing view deliberately.** At least one source must
   represent the strongest case against the emerging conclusion. If you
   can't find one, say you looked and what you searched — absence of
   opposition is itself a finding.
3. **Weigh, don't count.** Five weak sources don't outvote one strong one.
   Note where the evidence is thin.
4. **Synthesize to one page.** If it doesn't fit on a page, you haven't
   finished thinking.

## Output (one page max)

- **Executive summary** — one line.
- **Findings** — 3-5, each cited, primary/secondary marked, conflicts
  flagged inline rather than smoothed over.
- **The opposing view** — the strongest counter-case, argued fairly, with
  its sources.
- **Confidence & gaps** — what's solid, what's thin, what source would
  settle the open questions.
- **Source list** — every source with link and a one-clause credibility
  note.
