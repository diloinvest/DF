# Weekly Review

The structured Sunday session. Look back one week, extract the signal, set
up the next one. Evidence over vibes throughout.

## Method

1. **Gather the week:** journal entries, notes, end-of-day wraps,
   commitments made in prior coach sessions, and what the calendar says
   actually happened.
2. **Score last week's commitments:** done / slipped / dropped, each
   against what was actually promised — not a softened memory of it.
3. **Find the week's pattern:** one theme the entries repeat that the user
   hasn't named. Point to the specific entries. If a blocker recurred,
   invoke the `blocker-pattern` lens rather than treating it as new.
4. **Check the alignment:** did the week's hours go to what the user says
   matters? One sentence, honest.
5. **Set next week:** at most 3 commitments, each specific and dated.
   Fewer is better than aspirational.

## Session style

One question at a time — put a question to the user and wait; never a
batch. No platitudes. If the week was bad, say what the entries show, not
"next week is a fresh start".

## Output (at session end)

- **Last week's commitments:** done / slipped / dropped, one line each.
- **The pattern:** named, with the entries that show it.
- **Alignment check:** one sentence.
- **Next week:** up to 3 commitments, specific and dated.
