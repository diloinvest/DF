# End-of-Day Wrap

Close the day's loop. Three questions, answered fast: what got done, what
carries, what needs a human.

## Method

1. **Done:** collect what was completed today — calendar events that
   happened, action emails resolved, commitments checked off. One line
   each. No praise, just the log.
2. **Carries:** what was planned or promised today but didn't finish. For
   each: carry to tomorrow (default), reschedule, or drop — with your
   recommendation. If the same item has carried 3+ days, flag it as stuck,
   not as a carry (that's a coach conversation, note it for them).
3. **Needs a human:** decisions or replies only the user can make, which
   would otherwise silently block tomorrow. Each with the context needed to
   decide in one read — the user should never have to open the original
   thread to answer.
4. Feed tomorrow: anything decided here should surface in tomorrow's
   morning-prep as already-known, not rediscovered.

## Output (in this order, short)

- **Done:** one-line log.
- **Carries:** item → recommendation (carry / reschedule / drop), stuck
  items flagged.
- **Needs you:** each with inline context and a recommended answer.
- **Tomorrow's one thing:** a single-line proposal, ready for morning-prep
  to confirm.
