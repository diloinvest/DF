# Hackintosh USB — готов файл за флашка

Пълно ръководство за правене на bootable USB с macOS Tahoe (26) на Windows
машина, реконструирано от видеото
[„I Installed MacOS on a Windows Laptop!" — Gameboy Hub](https://youtu.be/gLpeLxPjMz4)
(13:54 мин., качено 04.07.2026).

**Как се ползва:** копирай цялата папка `usb-hackintosh/` на флашката (или
разпечатай `CHECKLIST.md`). Файлът е самодостатъчен — не иска интернет, за да
се чете.

> **Какво НЕ е включено:** самият образ `Tahoe.raw` (~15 GB, macOS е
> собственост на Apple — не мога да го генерирам или разпространявам). Той се
> сваля отделно; виж „Какво да си свалиш" по-долу. Тук е готова цялата
> процедура около него.

---

## 0. Преди да започнеш — проверка за съвместимост

Това е най-важната стъпка и във видеото авторът я казва изрично на 11:12:
**ако OpenCore Legacy Patcher каже, че нещо не се поддържа, не се хващай да го
поправяш след инсталацията — почти невъзможно е.**

| Компонент | В клипа (Lenovo IdeaPad Flex 5) | Резултат |
|---|---|---|
| CPU | Ryzen 3 (5-о поколение) | ✅ поддържа до macOS Tahoe 26 |
| Графика | интегрирана | ✅ работи |
| Звук | — | ⚠️ проработи чак след Software Update |
| Wi-Fi адаптер | неподдържан | ❌ не проработи — решение: USB-C → Ethernet адаптер |
| RAM | 8 GB | ✅ достатъчно |

Минимум по клипа: сравнително нов CPU, 8 GB RAM, USB флашка **64 GB**.

---

## 1. Какво да си свалиш (на Windows машината)

| Инструмент | За какво | Къде |
|---|---|---|
| `Tahoe.raw` (образ на macOS Tahoe) | самият инсталатор | от Hackintosh общността (напр. r/hackintosh, OSX-PROXMOX / „raw image" builds) |
| **balenaEtcher** | записва `.raw` на флашката | https://etcher.balena.io |
| **OpenCore Legacy Patcher** | генерира EFI папката за твоя хардуер | https://github.com/dortania/OpenCore-Legacy-Patcher |
| **MiniTool Partition Wizard Free** | прави и връща EFI дяла на флашката | https://www.partitionwizard.com |
| (по избор) USB-C → Ethernet адаптер | интернет, ако Wi-Fi не тръгне | физически хардуер |

Интернет е задължителен по време на стъпка 3 — OpenCore си сваля Python и
компонентите в движение.

---

## 2. Записване на образа (клип 02:55 – 04:08)

1. Инсталирай и пусни **balenaEtcher**.
2. `Flash from file` → избери `Tahoe.raw`.
3. Включи флашката (64 GB) → `Select target` → избери я.
   ⚠️ Всичко на флашката се изтрива. Провери, че си избрал правилното
   устройство.
4. `Flash` → потвърди с `Yes` → изчакай.

---

## 3. Генериране на EFI папката с OpenCore Legacy Patcher (04:08 – 06:45)

1. Пусни `.bat` файла **като администратор** (десен бутон → Run as administrator).
2. На всички предупреждения „Windows protected your PC" → `Run`.
3. Ако попита `Python was not found. Install?` → `Y` → Enter. Изчакай да свали
   всичко.
4. В главното меню → **`1`** (hardware report) → **`E`** (export).
   Инструментът разпознава CPU, графика, звук, мрежов адаптер.
5. **Прочети отчета.** Тук ще видиш докъде стига машината ти (в клипа: „up to
   macOS Tahoe 26") и кое не се поддържа (в клипа: мрежовият адаптер).
6. Enter за продължаване.
7. Избери версията за инсталиране → в клипа е **`25` = macOS Tahoe**.
8. Опция за аудио → **`1`**.
9. **`6`** = Build EFI folder → Enter.
10. Прочети предупрежденията за рисковете → напиши `yes` → Enter.
11. При въпроса за модел остави подразбиращото се → **`99`** → Enter.
12. „OpenCore EFI is complete" → Enter. **Премести генерираната `EFI` папка на
    Desktop**, за да я намираш лесно.
13. Enter → главно меню → изход.

---

## 4. Прехвърляне на EFI на флашката (06:45 – 07:56)

Тук е най-деликатната част — EFI дялът се трие, прави наново като FAT32, пълни
се и се връща обратно като EFI System Partition.

С **MiniTool Partition Wizard Free**:

1. Намери флашката в списъка — вече има `EFI` дял (от Etcher).
2. Десен бутон на EFI дяла → **Delete** → остава unallocated space.
3. Десен бутон на unallocated → **Create** → `Yes`.
4. Файлова система: **FAT32**. Име (label): **EFI**. → `OK`.
5. Долу вляво → **Apply** → `Yes` → изчакай.
6. Отвори File Explorer — новият `EFI` дял вече се вижда с буква.
   **Копирай генерираната `EFI` папка от Desktop вътре в него.**
7. Обратно в MiniTool: десен бутон на дяла → **Change Partition Type ID** → от
   първата опция избери **EFI System Partition** → `Yes` → **Apply**.

Флашката е готова.

---

## 5. Boot и инсталация (07:56 – 10:48)

1. Изключи компютъра. Влез в **BIOS/UEFI** и **изключи Secure Boot**.
   (В клипа първият опит гръмна точно заради това — 08:07.)
2. Boot menu → избери USB устройството.
3. В OpenCore менюто → слез до **Install macOS Tahoe** → Enter.
4. Зареждащ се macOS installer → изчакай.
5. **Disk Utility** → `Continue` → избери вътрешния диск.
   ⚠️ Тук се трие Windows и всичко на диска.
6. `Erase` → име: **Macintosh SSD**, формат: **APFS** → `Erase` → `Done`.
7. Изход от Disk Utility → **Install macOS Tahoe** → `Continue` → приеми
   условията → избери `Macintosh SSD` → `Continue`.
8. Инсталацията отнема **20+ минути**. Машината рестартира сама.
9. Setup: държава, клавиатура, тъчпад — работят.
   Ако Wi-Fi мрежите са сиви → избери **„My computer does not connect to the
   internet"** и продължи.
10. Име на акаунт + парола → през останалите екрани → **Get Started**.

---

## 6. След инсталацията — задължително

- **Копирай `EFI` папката от флашката върху EFI дяла на вътрешния диск.**
  Иначе машината няма да буутва без флашката. (11:26 в клипа.)
- **Пусни System Settings → General → Software Update и инсталирай ъпдейта.**
  В клипа точно това накара звукът да проработи (11:50).
- Ако Wi-Fi не работи: включи **USB-C → Ethernet адаптер**. Работи веднага.

---

## 7. Проблеми и решения

| Симптом | Причина | Решение |
|---|---|---|
| Флашката не се появява в boot menu | Secure Boot е включен | Изключи Secure Boot в BIOS |
| Wi-Fi мрежите са сиви / няма ги | неподдържан мрежов адаптер | USB-C Ethernet адаптер; не се поправя софтуерно |
| Няма звук | липсват ъпдейти | Software Update → инсталирай → рестарт |
| OpenCore казва „unsupported" за компонент | хардуерът не се поддържа | Не продължавай с надежда — след инсталацията не се оправя |
| macOS Golden Gate (след Tahoe) | Tahoe е последната версия с Intel поддръжка | Не е възможно да се hackintosh-не — само Apple Silicon |

## 8. Реалният резултат от клипа

Работи: CPU, графика, памет (разпознат като MacBook Pro), клавиатура, тъчпад,
звук (след ъпдейт), интернет през Ethernet адаптер.
Не работи: вграденият Wi-Fi.

---

**Правна бележка:** macOS EULA на Apple позволява инсталация само на хардуер с
марка Apple. Ръководството е за лична експериментална употреба на собствена
машина; наличието на самия образ е твоя отговорност.
