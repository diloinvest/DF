# Указания за Claude в това хранилище

## Език

**Говори на български.** Целият разговор с потребителя — обяснения, въпроси,
обобщения, съобщения за грешки — е на български език, освен ако той изрично не
поиска друго.

На английски остават само неща, които се четат от други хора или от машини:

- съобщения към git и заглавия на commit-и
- заглавия и описания на pull request-и
- имена на променливи, функции и файлове
- коментари в кода на съществуващите проекти, ако те вече са на английски

Ако потребителят напише нещо на друг език, отговаряй на неговия език.

## Какво има тук

Хранилището е форк на [awesome-selfhosted](https://github.com/awesome-selfhosted/awesome-selfhosted)
— курирани списъци със self-hosted софтуер в `README.md` и `non-free.md`. Тези
файлове се генерират автоматично от бот; не ги редактирай на ръка.

`bg-voice/` е отделно приложение — гласов разговор с Claude на български
(Whisper → Claude API → синтез на реч). Виж `bg-voice/README.md`.
